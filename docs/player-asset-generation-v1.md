# ColonistSaga Player Portraits V1

Generated July 18, 2026 with OpenAI's built-in image generation tool. These
opaque 1:1 portraits were explored as player-seat characters while all names,
status, scores, and controls remain code-rendered.

## Shared Prompt

```text
Use case: stylized-concept
Asset type: ColonistSaga player HUD portrait, square 1:1 raster badge
Style/medium: polished original casual-game 3D clay illustration, rounded handcrafted forms, warm soft upper-left lighting, crisp silhouette and facial readability at 48px
Composition/framing: centered shoulders-up portrait, facing slightly toward camera, generous breathing room, no crop through head, simple circular island-sky backdrop contained inside the square
Constraints: one original adult island explorer, friendly confident expression, no text, no letters, no logo, no watermark, no weapons, no board-game pieces, no copyrighted character or franchise likeness, opaque finished background, cohesive with bright honey-gold and turquoise ColonistSaga UI
```

## Seat variants

- Red navigator: a warm, adventurous woman harbor navigator with dark wavy
  hair, a subtle red scarf, and a practical ivory sailing jacket.
- Blue cartographer: a calm island cartographer with a blue neckerchief and an
  ivory field jacket.
- Orange builder: a cheerful village builder with an orange bandana and an
  ivory work jacket.
- Green botanist: a thoughtful island botanist with a green scarf and an ivory
  explorer jacket.
- Purple astronomer: a curious island astronomer with purple accents and a
  compact brass telescope detail.
- Teal shipwright: a capable harbor shipwright with teal accents and a polished
  wood tool detail.
- Yellow merchant: a welcoming island merchant with golden-yellow accents and
  a small trade-ledger detail.
- Pink pathfinder: an optimistic island pathfinder with pink accents and a
  compact compass detail.
